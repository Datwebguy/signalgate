# Stack

Keep it boring so the network integration is the work.

Suggested default:

- TypeScript
- Next.js app router or Vite + a small Node server
- Official `telegraphprotocol/telegraph-mcp` or Engine HTTP + x402 fetch
- sqlite for run logs unless a hosted DB is already available
- Vercel / Fly / Railway for the public URL
- A cron or long-running worker for the watchlist

Do not add a second intelligence vendor.
